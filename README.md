# Proyecto TicTacToe - Cuatro en Raya

este programa es un juego de tres en raya que es con una persona contra la maquina.
el programa tiene un total de 9 cuadros y el usuario siempre van a ser las "X" y el computador "O"

el programa es sencilla de forma visual ya que no cuenta con decoracion extra, no hay ninguna modificacion extra
es el tipico tres en raya que todo el mundo conoce.
